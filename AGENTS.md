# Course repository guidance

- Keep examples small enough to understand without a framework.
- Every agent action that changes external state must support dry-run or approval.
- Never commit secrets, customer data, OAuth tokens, or production exports.
- New labs must state objectives, prerequisites, exercises, deliverables, and acceptance criteria.
- Prefer deterministic code for business rules; use a model only for semantic judgment.
- Add tests for tool schemas, orchestration transitions, permissions, and failure paths.
